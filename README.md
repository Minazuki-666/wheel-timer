# タイマーアプリ - Web版

HTML、CSS、JavaScriptで作成されたマウスホイール対応タイマーアプリです。

## 🌟 特徴

- **🖱️ マウスホイール対応**: 時間、分、秒をマウスホイールで直感的に調整
- **⚡ クイック設定**: よく使う時間をワンクリックで設定
- **🎵 音響通知**: Web Audio APIによる確実な音響通知
- **📱 レスポンシブデザイン**: スマートフォンやタブレットでも快適
- **⌨️ キーボードショートカット**: キーボードでも操作可能
- **🔧 デバッグモード**: 開発者向けのデバッグ機能

## 🚀 実行方法

### 方法1: ローカルサーバー（推奨）
```bash
# Pythonを使用（Python 3の場合）
cd web
python -m http.server 8000

# または Node.jsを使用
npx http-server web

# ブラウザで http://localhost:8000 にアクセス
```

### 方法2: 直接ファイルを開く
`web/index.html`をブラウザで直接開く（一部機能に制限あり）

## 🎮 使い方

### 1. 時間設定
- **マウスホイール**: 各時間単位の白いボックスでホイールを回す
- **▲▼ボタン**: マウスクリックで微調整
- **クイック設定**: 30秒、1分、5分、10分、15分、30分をワンクリック

### 2. タイマー操作
- **▶ スタート**: タイマー開始（緑ボタン）
- **⏸ 一時停止**: タイマー一時停止（青ボタン、実行中は「▶ 再開」に変化）
- **🔄 リセット**: タイマーリセット（赤ボタン）
- **🔊 音テスト**: 音響機能テスト（紫ボタン）

### 3. キーボードショートカット
- **Enter**: タイマー開始
- **Space**: 一時停止/再開
- **Escape** または **R**: リセット
- **Ctrl+D**: デバッグモード切り替え

## 🎵 音響機能

### Web Audio API
- 高品質な音響生成
- カスタム周波数による通知音
- ブラウザネイティブサポート

### 音響パターン
タイマー完了時に3つの音が順番に再生：
1. **高音（880Hz）**: 0.3秒
2. **中音（659Hz）**: 0.3秒  
3. **高音（880Hz）**: 0.3秒（強調）

### 視覚通知
- **赤色強調表示**: タイマー完了時に画面が赤くなる
- **絵文字メッセージ**: 🎉 タイマー終了！ 🎉
- **自動復帰**: 3秒後に通常表示に戻る

### トラブルシューティング
音が鳴らない場合：
1. ブラウザの音量設定を確認
2. サイトの音声許可設定を確認
3. 🔊音テストボタンで個別テスト
4. 他のタブで音が鳴るか確認
