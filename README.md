# タイマーアプリ - マウスホイール調整対応

マウスホイールで直感的に時間設定ができるタイマーアプリです。

## 特徴

- **マウスホイール調整**: 時間、分、秒それぞれをマウスホイールで簡単に調整できます
- **直感的なUI**: 時間設定エリアは視覚的に分かりやすく設計されています
- **増減ボタン**: マウスホイールが使えない環境でも▲▼ボタンで調整可能
- **キーボードショートカット**: 基本操作をキーボードでも実行できます
- **レスポンシブデザイン**: ウィンドウサイズに応じてフォントサイズが自動調整されます

## 使い方

### 1. 時間設定
- 各時間単位（時間、分、秒）のエリアの上でマウスホイールを回して時間を調整
- ホイール上回転: 値を増加
- ホイール下回転: 値を減少
- 最大値を超えると0に戻り、0未満になると最大値に戻ります（循環）
- 各エリアの▲▼ボタンでも調整可能

### 2. タイマー操作
- **スタートボタン**: タイマーを開始
- **一時停止ボタン**: タイマーを一時停止/再開
- **リセットボタン**: タイマーをリセットして時間設定を0に戻す

### 3. キーボードショートカット
- **Enter**: タイマー開始
- **Space**: 一時停止/再開
- **R**: リセット
- **Escape**: 実行中のタイマーをリセット

### 4. 時間設定の範囲
- **時間**: 0-23（24時間表示）
- **分**: 0-59
- **秒**: 0-59

## 実行方法

```bash
cd timer-app
python src/main.py
```

## システム要件

- Python 3.6以上
- Tkinter（通常Pythonに標準で含まれています）
- Windows（通知音にwinsoundを使用）

## 機能詳細

### マウスホイール操作
各時間単位のエリア（白い背景のボックス）にマウスカーソルを合わせてホイールを回すことで値を調整できます。値は循環するため、直感的に操作できます。

### タイマー完了通知
タイマーが終了すると：
- 画面に「タイマー終了！」メッセージが表示
- システム音（ビープ音）が1秒間鳴ります

### レスポンシブデザイン
ウィンドウサイズを変更すると、フォントサイズが自動的に調整され、見やすさを保ちます。
